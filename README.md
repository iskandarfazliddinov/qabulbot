# Qabul boti — t.me/qabulakadembot

## Куда вписать токен и ID
Есть два равноценных способа. Бот сначала смотрит переменные окружения, потом config.txt.

**Способ A — файл config.txt** (для своего компьютера):
```
BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxx
ADMIN_IDS=205409821
OQIM=III oqim
```
Только текст после `=`. Без кавычек и пробелов. Несколько админов — через запятую: `205409821,123456789`.

**Способ B — переменные окружения** (для сервера Railway / Render / Koyeb / Fly и т.п.):
в панели сервиса раздел *Variables / Environment* → добавить три переменные:
| Name | Value |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | ваш ID от @userinfobot |
| `OQIM` | `III oqim` |

Тогда config.txt можно не загружать вообще.

## Запуск
- Свой компьютер (Windows): двойной щелчок `start.bat`.
- Сервер: команда запуска `python bot.py`. Тип сервиса — **worker / background**, не web
  (боту не нужен порт). В комплекте есть `Procfile` и `Dockerfile` — платформа подхватит сама.
- Python 3.10+. Зависимости в `requirements.txt`.

Запускайте бота **только в одном месте**. Две копии с одним токеном одновременно
(например, сервер + ваш ПК) ломают друг друга — Telegram выдаёт ошибку Conflict.

## Данные не теряются (автокопия в Telegram)
Через ~2 минуты после новых регистраций бот присылает первому администратору
(первый ID в `ADMIN_IDS`) файл `oqim.db` и закрепляет это сообщение в чате.
Если сервер перезапустился и стёр файлы — при запуске бот сам скачает закреплённую
копию и восстановит список. **Не удаляйте закреплённое сообщение с файлом oqim.db.**
`/backup` — прислать копию прямо сейчас.

## Команды администратора
| Команда | Результат |
|---|---|
| `/stats` | счётчики по районам, направлениям и сменам |
| `/export` | Excel по каждому району (Bo'stonliq, Parkent, Boshqa tuman) |
| `/export parkent` | один район: `parkent`, `bostonliq`, `other` |
| `/backup` | прислать копию базы сейчас и закрепить |

Excel: лист `Baza`, заголовки в строке 4, данные с 5-й.
Столбцы: T/r, F.I.O., Tuman, Tug'ilgan sana, Pasport, Ma'lumoti, Yo'nalish, Smena,
Telefon, Qo'shimcha telefon, Manzil, Ro'yxat sanasi, Telegram.

## Что меняется при новом потоке
`OQIM` → например `IV oqim`. Даты и площадки — словарь `DISTRICTS` в начале `bot.py`.
Старые записи остаются в базе, экспорт показывает только текущий поток.
